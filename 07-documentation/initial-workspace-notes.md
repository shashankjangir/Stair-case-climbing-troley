## How to use this workspace

1. Start by describing the problem and how the idea came to you.
2. Record your sources and compare possible mechanisms before choosing a design.
3. Save editable CAD files alongside useful exports and drawings.
4. Document fabrication and tests with dated notes and photos.
5. Update the progress log when you complete a milestone or change the design.

Use descriptive filenames such as `2026-10-10-initial-sketch.jpg` or `wheel-carrier-v01.step`. Record units with every measurement and distinguish planned values from measured results.

## Preserve ideas and versions

Keep earlier work whenever a better solution is found. Add a new heading such as `V2 - Improved wheel arrangement`, or save a new file such as `wheel-carrier-v2.step`. Continue with v3, v4, and so on; do not overwrite the previous version.

For each improvement, record the date, what changed, why it changed, and which version it replaces. Mark earlier versions as superseded when appropriate while keeping their contents available. Keep older CAD assemblies and the parts they depend on together so they remain usable.

This applies to ideas, research, calculations, CAD, mechanical work, and test results. Project assistants must follow the same rule in [AGENTS.md](../AGENTS.md).
