## Initial planning record

The aim is a manually operated tri-star trolley that can transport a chosen payload over measured stairs, maintain control through repeated steps, and reduce manual pull force compared with a regular trolley.

The values below still need to be chosen or measured. Update this document as those decisions are made.

## Performance goals and acceptance criteria

Set numerical limits before testing rather than choosing them after seeing the results.

| Goal | What will be checked | Limit or target |
| --- | --- | --- |
| Smooth stair traversal | Completed transitions, catches, interruptions, and visible load movement; add an acceleration measure if equipment permits. | To be set. |
| Manageable torque and effort | Calculated climbing torque and measured peak and average handle pull force. | To be set. |
| Stable load distribution | Load position, tilt, support contacts, and rollover tendency throughout a flight. | Allowed payload positions and stability criteria to be set. |
| Structural rigidity | Deflection under load, residual deformation after unloading, and joint condition. | Allowable deflection and residual set to be set. |
| Dynamic payload operation | Repeated climbs with secured payloads while the trolley is moving. | Payload levels and repetition count to be set. |
| Reduced manual pull force | Comparison against a regular trolley under matched test conditions. | Required improvement and measurement uncertainty to be set. |
| Controlled descent | Ability to lower the load through consecutive steps without loss of control. | Procedure and acceptance criteria to be set. |

## Design constraints

Record restrictions on overall width, handle reach, storage, material availability, cost, and assembly tools. Keep measured values separate from estimates. Any later change to a requirement should include a short reason in the normal work notes.

## Context from the earlier build

The original report mentions a 30–50 kg load-testing range and a platform designed for up to 50 kg. It also records slight tilting with heavier loads. The individual test loads, loading positions, and measurements are not included.

These figures are historical reference points, not an established rating or a selected requirement for the current build. The payload target above remains open until it is chosen and supported by calculations and testing. Include load balance, traction, and cost in that decision.
